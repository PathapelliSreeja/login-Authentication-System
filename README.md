# 🔐 Login & Authentication System

A simple and beginner-friendly **Login & Authentication System** built using **HTML, CSS, and JavaScript**.

This project provides a basic user registration and login interface with form validation and a dashboard.

## 📌 Features

* 📝 User Registration
* 🔐 User Login
* ✅ Form Validation
* 👤 Username/Email & Password Validation
* 🏠 Dashboard
* ⚠️ Error Handling
* 📱 Clean and Responsive User Interface
* 🚪 Logout functionality

## 🛠️ Technologies Used

* **HTML5** – Structure of the application
* **CSS3** – Styling and responsive design
* **JavaScript** – Form validation and authentication logic

## 🚀 How to Run

```bash
git clone YOUR_GITHUB_REPOSITORY_LINK
```

### 2. Open the project

Open the project folder in **VS Code**.

### 3. Run the project

Open `index.html` in your browser.

You can also use the **Live Server** extension in VS Code.

## 💡 How It Works

1. Open the application.
2. Register with the required details.
3. Enter your login credentials.
4. JavaScript validates the entered information.
5. If the details are valid, the user can access the dashboard.
6. The user can logout and return to the login page.
